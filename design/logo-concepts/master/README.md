# Anna Relay master

Selected master: restrained Relay with equal outer heights and the broader original colour progression.

## Files

- `anna-relay-mark.svg`: transparent full-colour master mark.
- `anna-relay-mono.svg`: single-colour master mark.
- `public/brands/anna.svg`: production avatar with the Anna navy tile.
- `public/favicon.svg`: identical production avatar for browser-icon use.
- `public/brands/anna.png`: 192 px compatibility export of the production avatar.

## Palette

- Anamata blue: `#2C548C`
- Transition cobalt: `#3159C7`
- Relay violet: `#8D4DFF`
- Anna coral: `#FF5C42`
- Anna navy: `#08152E`

The gradient is spatial, running once across the complete mark. Both sides share equal top and bottom extents. The separated diagonal pieces remain part of the master silhouette.
