# Anna identity concepts: round 1

Exploratory vector boards only. These files are not wired into the Anna site.

1. `01-anna-relay.svg`: AN/NA Relay, derived from the broken diagonal in the Anamata wordmark.
2. `02-anna-palindrome.svg`: bilateral form based on Anna's palindromic name.
3. `03-anna-character.svg`: a mature companion-avatar direction with an asymmetrical signature sweep.

Each board includes a primary lockup, avatar treatment, monochrome form, and small-size test. They are discussion drafts rather than production marks.
