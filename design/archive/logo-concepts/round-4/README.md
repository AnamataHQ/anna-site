# Anna Relay master candidate 04

This review package corrects the two refinements requested for the Relay master:

- The violet transition is concentrated tightly around the central handoff.
- Every outer stem ends on the same `y=42` top line or `y=158` bottom line.

Included applications:

- Full color on transparent
- Full color on black
- Full color on Anna navy (`#08152E`)
- Dark monochrome on transparent
- Light monochrome on transparent

These files are review-only. No production asset has been replaced by this round.
