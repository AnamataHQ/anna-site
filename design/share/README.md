# Share card

`anna-share.html` is the source of `public/share/anna-1200x630.png`, the image a link to the site shows in Teams, LinkedIn, WhatsApp and similar (wired up in `app/layout.tsx` as `openGraph` and `twitter` images, with `metadataBase` pointing at production). To regenerate it, serve the repository root with any static server (for example `python3 -m http.server 8123` from the repo root), open `http://localhost:8123/design/share/anna-share.html` in a headless browser with the viewport set to exactly 1200×630 and device scale factor 1, wait until fonts have loaded (`document.fonts.ready`; the template pulls Geist from Google Fonts, so the browser needs network access), take a viewport (not full-page) PNG screenshot to `public/share/anna-1200x630.png`, then check the result with `wc -c public/share/anna-1200x630.png` (at most 153600 bytes, 150 KB) and `npm test`, whose site-contract test also checks the PNG header for 1200×630; if the file is too large, run it through a lossless optimiser such as `oxipng -o 4` rather than changing the design.
